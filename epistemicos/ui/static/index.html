    Benchmark Methodology & Artifact Scope

    EPISTEMIC LIMITATIONS NOTICE:

    • The Benchmark Workbench displays recorded evidence from static JSON artifacts (results/ablation_table.json and results/per_case_results.json).
    • Parsing success confirms syntactic readability of JSON artifacts only—it does NOT establish empirical validity, reproducibility, or external system safety.
    • Aggregated accuracy, precision, and recall metrics reflect performance on the specific N=100 held-out evaluation dataset and configured baseline conditions.
    • Individual case classification labels (TC/FC/TR/FR) reflect automated comparison against expected outcomes, not human adjudication or external source authenticity.
    • Presence of SHA-256 digest strings proves record inclusion in JSON artifacts, but does NOT constitute external cryptographic verification against raw dataset files.

    Unavailable Analysis Scope

    UNAVAILABLE ANALYSES NOTICE:

    • Statistical Power / Sample Size Sensitivity: Cannot be derived because artifacts do not include resampling/bootstrap distributions.
    • Continuous Logprob ROC-AUC Curves: Cannot be computed because raw token logprob distributions are omitted from per-case summary records.
